# Contributing

Issues and pull requests are welcome.

1. Fork the repository and create a branch from `main`.
2. Use `pnpm install`, then `pnpm type`, `pnpm lint`, and `pnpm build` before opening a PR.
3. Keep the default light theme usable, and do not add official DeepSeek logos or trademarks as the app identity.
4. Do not commit API keys, keystores, or `keystore.properties`.

中文说明：请从 `main` 开分支，提交前运行 `pnpm type`、`pnpm lint` 和 `pnpm build`。不要把官方 DeepSeek 标识当作本应用的品牌，也不要提交密钥或签名证书。
